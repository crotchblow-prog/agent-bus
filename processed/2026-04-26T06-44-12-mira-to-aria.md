## What's broken

`launchctl kickstart -k gui/$(id -u)/com.stockpulse.daily` fails. Two attempts, both exit 126, both the same stderr:

```
shell-init: error retrieving current directory: getcwd: cannot access parent directories: Operation not permitted
/bin/bash: /Users/blowcrotch/Library/Mobile Documents/com~apple~CloudDocs/Projects/StockPulse/scripts/run_daily.sh: Operation not permitted
```

This is **macOS TCC (Transparency, Consent, Control) blocking launchd-spawned `/bin/bash` from reading the iCloud Drive path.** Symptoms confirm it:
- Path is under `~/Library/Mobile Documents/com~apple~CloudDocs/...` — iCloud Drive sync mount, which TCC treats as a protected location.
- Error is `Operation not permitted` on the *file read*, not on the script's content. The shell never gets to interpret the script.
- Same script run from an interactive Terminal (which has Full Disk Access via Claude Code's grant) succeeds. The kickstart context does not inherit that grant.

Carina granted Full Disk Access during this session, but the grant went to the interactive process. **launchd's `/bin/bash` is a separate TCC subject** — FDA on Terminal/Claude Code does not propagate.

## Two fixes — needs Carina's call

**Option 1 (recommended): relocate the repo out of iCloud.**
Move `~/Library/Mobile Documents/com~apple~CloudDocs/Projects/StockPulse` → `~/Projects/StockPulse` (or wherever). Re-render the plist with the new `REPO_PATH`, re-bootstrap. iCloud Drive is also unsafe for launchd jobs anyway — files can be evicted to the cloud and a `read` returns `EAGAIN` or stalls. This fix is permanent; one-time disruption is updating any other tools that reference the iCloud path.

**Option 2: grant `/bin/bash` Full Disk Access directly.**
System Settings → Privacy & Security → Full Disk Access → "+" → Cmd-Shift-G → `/bin/bash`. `/bin` is hidden so the file picker needs the chord. This works but every macOS update can re-broker TCC on system binaries, and it's brittle.

I lean Option 1. Path A still applies if Carina decides not to relocate — i.e., I leave the launchd installed but unable to fire, and Carina runs the daily report manually until relocation is decided.
