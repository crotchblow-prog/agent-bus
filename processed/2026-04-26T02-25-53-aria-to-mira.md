## Files to create

### `scripts/analyzers/flags.py` (new)

Pure function over technicals + tags + earnings + tier. Closed vocabulary, stable order for diffing.

**Vocab — exactly these 17, in this order (FLAG_VOCAB):**

```
Momentum:   oversold_rsi (rsi<30), overbought_rsi (rsi>70)
Trend:      near_50dma (|pct|<2%), below_50dma (<-5%), below_200dma (<0)
Extremes:   near_52w_low (<5%), near_52w_high (>-2%), deep_drawdown (<-30%)
P&L:        underwater (vs_cost<-10%), big_gain (vs_cost>20%)
Calendar:   earnings_within_7d, earnings_within_3d (3d implies 7d)
Tags:       high_risk_tag, event_play (muddy_waters_target etc.)
Tier:       buy_list_member, sell_list_member,
            beta_size_warn (high_beta tag + tier_index<=1)
```

**Function signature:** takes a dataclass `FlagInputs`, returns `list[str]` in `FLAG_VOCAB` order. Provide `is_watchworthy(flags: list[str]) -> bool` helper that excludes pure `buy_list_member` for Watch List filtering.

### `scripts/reporters/json_emitter.py` (new)

Writes `{date}.json` + `latest.json` next to the Markdown. **This is THE synthesis contract.** Schema:

```

date, vix_value, tier (full TierResult), snapshot, holdings, accounts,
optional synthesis block
```

Bump `schema_version` on any field rename or removal. Coerce NaN/Inf → null.
