## Test isolation note

Two file-mutating tests (the synthesis-missing variants in `v2-m2-synthesis-missing.spec.ts`) mutate `web/public/reports/en/latest.json` then restore in finally. Without serialization they raced with parallel tests on /en that read the file. Fix: `workers: 1` in `playwright.config.ts` — small suite (30 tests, ~20s) so the speed cost is fine. Documented in the config + spec comments.

If you'd rather refactor to use Playwright's `page.route()` interception (so file mutation isn't needed), flag and I'll do it as a follow-up — but it requires the v2 page to fetch JSON via HTTP rather than `fs.readFile`, which is a non-trivial architectural change for negligible benefit.
